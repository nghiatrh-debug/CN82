# CN8-2 Project Control Dashboard

## Chạy nội bộ

```powershell
node .\dashboard\server.mjs
```

Mở `http://localhost:4173`.

- Dữ liệu hiện hành được tổng hợp từ báo cáo ngày 24/06/2026, WR-13 ngày 18/06/2026, biên bản giao ban 19/06/2026, biên bản MEP 25/06/2026 và báo cáo Inclinometer CK12.
- Module Kế hoạch 3 tuần sử dụng `CN8-2-VC-Civil-DS-13rev03 - Overall Construction Schedule Rev01`, đã duyệt SPM ngày 11/05/2026.
- Các trạng thái quan trắc là phân loại quản trị sơ bộ, chưa thay thế ngưỡng cảnh báo được phê duyệt.
- Phiên bản tiếp theo cần bổ sung dịch vụ đồng bộ Google Drive, cơ sở dữ liệu, đăng nhập và quy trình xác nhận dữ liệu.
