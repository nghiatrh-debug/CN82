# Construction KPI Reference

## Executive KPIs

| KPI | Calculation / evidence | Owner-side interpretation |
|---|---|---|
| Planned progress | Approved baseline or accepted update | Contractual/approved expectation |
| Actual progress | Latest checked report | Current delivery state |
| Variance | actual - plan | Negative requires recovery action |
| Delay days | Schedule analysis or approved report | Show basis and cut-off |
| Lookahead milestone compliance | completed milestones / due milestones | Leading delivery indicator |
| Manpower/equipment | Latest daily report | Compare with recovery commitment |
| Overdue actions | open actions past due | Management accountability |
| Submission aging | current date - submission date | Design/procurement constraint |
| Monitoring exceptions | readings beyond approved threshold | Safety escalation only with threshold |
| Cost variance | forecast/EAC vs approved budget | Requires commercial data completeness |

## Quality and HSE

Track NCRs, inspections, test results, incidents, permits, personnel/equipment validity, and corrective actions. Do not use a green status merely because a daily report says “ensured”; require evidence or accepted reporting rules.

## Alert Content

Every alert should include:

1. observed condition;
2. baseline or threshold;
3. impact;
4. accountable party;
5. required date;
6. source document;
7. recommended owner action.
